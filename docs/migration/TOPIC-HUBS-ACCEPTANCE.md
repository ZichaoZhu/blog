## 500 篇同规模比较

同一 Node 22.23.0、pnpm 11.22.0、机器和 preview 模式；使用相同 44 份正文生成同样的用途分布：course 200、paper 180、log 50、idea 30、experiment 20、note 20。真实内容库没有生成样本。以下规模与网络数据对应 `e3d8c1c` 的顺序读取实现；随后目录监听器清理补丁通过全套回归，未重复规模采样。

| 指标 | 改造前 | 初次改造后 | 最终顺序读取 |
| --- | ---: | ---: | ---: |
| 构建秒数 | 70.538 | 71.187 | 77.186 |
| 峰值 RSS，bytes | 3,158,130,688 | 3,999,449,088 | 3,218,784,256 |
| 唯一公开正文／Pagefind 页 | 500 | 500 | 500 |
| Notes 兼容分页 | 20 | 20 | 20 |
| 全部集合分页 | — | 94 | 94 |

初次峰值增长 26.6%，统计适配层同时加载 500 份渲染模块是可移除的并发压力。改用原生顺序读取后，该样本峰值相对基线增长 1.9%，构建耗时增长 9.4%；相比初次样本峰值降低约 19.5%，耗时多约 6 秒。采用“峰值增长超过 15% 就调查”的本机判据，先观察失败，再验证通过。三个单次测量保留，不能据此保证所有机器的耗时或内存上限。

最终模型核对 725 次主题成员归属，全站仍为 500；课程数量为编译原理 70、操作系统 82、强化学习 30、Deep Learning for Vision 0、日语 18。94 个集合页面逐页检查成员／讲次顺序和每页 ≤25 项；无越界产物、无 draft 哨兵、Pagefind 精确哨兵查询无结果。导航只含当前专题／当前课程，无正文或全站文章数组下发。

新增真实主题分页使静态 HTML 页数从 633 增至 690，HTML 产物从 153,040,930 增至 166,843,403 bytes；Pagefind 产物约 4.81 MB，前后相差 11 bytes。该磁盘体积不是访客一次下载量。
